## Tips for a great README

- **Lead with the essentials.** Explain what the project is, who it is for, and why it matters.
- **Make it scannable.** Use clear headings, short paragraphs, lists, and useful links.
- **Show, do not decorate.** Screenshots, demos, and badges should add context rather than noise.
- **Keep it accessible.** Add useful alt text, avoid relying on color alone, and offer a non-animated way to understand important content.
- **Check mobile rendering.** Wide tables, huge images, and excessive badges can be difficult to read on small screens.
- **Keep information current.** Verify links, installation steps, and generated widgets periodically.
- **Be mindful of privacy.** Do not publish private data, secret tokens, or sensitive analytics in a README.
